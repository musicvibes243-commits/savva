# SAVVA — قهوة مختصة

Сайт спешелти-кофейни SAVVA (Медина, квартал Бир-Усман). Учебный проект.

Один файл `index.html` без сборки и зависимостей: открывается двойным кликом,
работает с телефона, из папки и с GitHub Pages.

## Концепция: «Арка»

Арочная дверь и арочное окно — то, что первым видишь в SAVVA вживую. Эта форма
стала конструктивным элементом всего сайта, а не украшением:

| где | как |
| --- | --- |
| Герой | видео заварки внутри арки с деревянной рамой — «взгляд через дверь кофейни» |
| Меню | каждая карточка блюда — арка |
| Галерея | фотографии в арочных рамах |
| О нас | фото в форме той самой органичной ниши со стены, где висят буквы SAVVA |

Палитра взята с фотографий заведения: травертин стойки, терракота вывески,
оливковая ткань диванов, тёплое дерево рам.

Шрифты: **Prata** (заголовки, есть кириллица), **Manrope** (текст),
**JetBrains Mono** (цены и подписи), **Reem Kufi** + **Noto Sans Arabic**
(арабская версия).

## Что умеет

- **Три языка: русский, English, العربية.** Арабская версия — полноценный RTL:
  меняется `dir`, зеркалится вся вёрстка, подменяется пара шрифтов. Язык
  определяется по браузеру и запоминается.
- **Конструктор чашки.** Основа, молоко, характер и размер — живая SVG-графика
  (слои напитка, лёд, трубочка, пар), пересчёт цены и генерация названия.
- **Живой статус «сейчас открыто»** — считается по реальному времени в Медине
  (`Asia/Riyadh`) и расписанию: закрытие в 2:00, по пятницам открытие в 13:00.
- **Дневная и вечерняя темы**, тоже с запоминанием.
- Фильтр меню, просмотр фотографий с клавиатуры, параллакс, плёнка зерна.
- Работает без JS: заставка уходит сама, контент виден (`<noscript>`-стили).
- Уважает `prefers-reduced-motion`.

## Почему именно этот вариант

В `mockups/` лежат три варианта арт-дирекции с одинаковым контентом — чтобы
сравнение было честным. Замеры сделаны по отрисованным пикселям в Chromium
(контраст текста считается относительно реального фона под ним):

| вариант | контраст H1 | контраст текста | площадь текста ниже нормы | вес 1-го экрана |
| --- | --- | --- | --- | --- |
| 1 · «Арка» | 10.7:1 | 5.0:1 | 0% | 435 КБ |
| 2 · «Витрина» | 5.0:1 (минимум 2.8:1) | 4.7:1 | 2.3% | 652 КБ |
| 3 · «Газета» | 13.4:1 | 5.3:1 | 0% | 274 КБ |

«Витрина» — крупный текст поверх фотографии — проигрывает объективно: заголовок
местами падает до 2.8:1 при норме 4.5:1, потому что попадает на светлую
травертиновую стойку. Лечится только затемнением фото, а это убивает саму идею.
Плюс самый тяжёлый первый экран.

«Газета» выигрывает по цифрам, но проигрывает по задаче: это сильная
типографика, которая не показывает место. У SAVVA главный актив — интерьер,
и вариант, который прячет фотографии, продаёт кофейню хуже.

«Арка» проходит все требования по контрасту, при этом строит форму из реальной
архитектуры заведения — такого решения нет у соседних кофеен, и оно не
случайное, а выведенное из фотографий. Поэтому в работу пошёл он.

## Доступность

Весь текст проверен замером по пикселям в обеих темах — минимум **4.7:1** при
норме WCAG AA 4.5:1. По ходу проверки пришлось поправить: ослабить плёнку зерна
(при multiply 0.34 она гасила контраст светлых фонов), затемнить вторичный текст
и терракоту для мелких надписей, а ночью сделать подпись кнопки тёмной.

## Бронь и оплата

Бэкенда у сайта нет, поэтому и бронь стола, и заказ из конструктора уходят
готовым текстом в WhatsApp кофейни — человеку остаётся нажать «Отправить».
Форма проверяет имя, дату (прошедшую не пропускает), время и число гостей;
если браузер заблокирует всплывающее окно, вместо тишины появляется ссылка,
которую можно открыть руками. Сообщение собирается на том языке, на котором
человек смотрит сайт.

Всё, что меняется руками, лежит тремя строками в начале скрипта:

```js
var WA_PHONE = '966564370303';   // куда уходят бронь и заказ
var VK_URL   = '';               // пусто — значок ВКонтакте скрыт
var PAY_REQ  = '';               // пусто — вместо реквизитов предлагаем WhatsApp
```

`PAY_REQ` пуст намеренно: кнопка «Оформить заказ» честно говорит, что оплата
картой ещё не подключена, и предлагает отправить заказ бариста. Как появятся
реквизиты — вписать их в эту строку, разметку трогать не нужно.

## Страница 404

Отдельная арт-дирекция, сделанная по референсу, который прислал заказчик
(404-страница Wolff Olins): кадр во весь экран, приглушённый почти до монохрома
и накрытый полиграфическим растром, поверх — крупная антиква, мелкий
моноширинный подзаголовок и одна ссылка с акцентным подчёркиванием.

Фоном идёт то же видео, что и на главной. Страница не тянет ни одной внешней
картинки из разметки: пути к видео, постеру и ссылка на сайт вычисляются из
адреса в JS. GitHub Pages отдаёт `404.html` из корня сайта по любому адресу
внутри него, поэтому относительные пути из разметки с вложенного адреса
указывали бы в никуда.

Замер контраста сделан по самому светлому кадру видео (худший случай): кикер
5.8:1, подпись ссылки 12.8:1, заголовок 14.9:1, `SPECIALTY COFFEE` 5.2:1.
Без JS пустой `<video>` спрятан — иначе Chromium рисует его чёрным
прямоугольником поверх постера и добавляет полосу плеера.

## Структура

```
├── index.html          весь сайт
├── 404.html            страница 404
├── images/             фотографии (пережаты: 10.9 МБ → 4.5 МБ)
├── videos/hero-reel.mp4  + .webm — VP9 для сборок без проприетарных кодеков
├── mockups/            три варианта арт-дирекции для сравнения
└── .nojekyll           Pages отдаёт файлы как есть, без сборки Jekyll
```

Публикуется через GitHub Pages с ветки `main`, папка `/` (корень).

Фотографии и видео — из самой кофейни. Тексты отзывов — с Google Карт.

Единственное исключение — ролик с котом в блоке «Не только люди»: он сгенерирован
нейросетью, и страница говорит об этом прямо подписью «Кот сгенерирован. Стаканы
настоящие». Стаканы на нём действительно фирменные.
